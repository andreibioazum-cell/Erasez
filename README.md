# Erasez

Мини-«Майнкрафт» для Android на чистом C + OpenGL ES 2.0 (без движков).

Вид **от первого лица**: вы ходите по процедурно сгенерированному миру,
сложенному из блоков (холмы, биомы: снежная тундра / леса / пустыня,
деревья и каменные выступы). Каждый мир генерируется заново из
детерминированного шума при первом запуске.

## Управление

| Действие | Как |
|---|---|
| Движение | Левый нижний угол — виртуальный джойстик |
| Поворот камеры | Тащить пальцем по свободной области экрана |
| Прыжок / вверх в полёте | Круглая кнопка справа внизу (стрелка вверх) |
| Включить/выключить полёт | Кнопка со стрелками «вверх-вниз» над кнопкой прыжка |
| Спуск в полёте | Кнопка со стрелкой вниз (появляется левее прыжка в полёте) |

> Не удержались на краю мира — просто снова появитесь на стартовой поляне.

## Как собрать APK

Проект собирается в CI (GitHub Actions) — см. `.github/workflows/main.yml`:

```bash
# локально (нужен Android NDK):
TOOLCHAIN=$ANDROID_NDK_ROOT/toolchains/llvm/prebuilt/linux-x86_64/bin
GLUE=$ANDROID_NDK_ROOT/sources/android/native_app_glue
FLAGS="-O2 -s -fPIC -shared -I. -I$GLUE -landroid -llog -lGLESv2 -lEGL -lm"
$TOOLCHAIN/aarch64-linux-android21-clang main.c $GLUE/android_native_app_glue.c -o libmain_64.so $FLAGS
```

## Структура

- `main.c` — точка входа, EGL, игровой цикл;
- `engine.h` — состояние игры и константы мира;
- `world.h` — генерация мира (fBm-шум, биомы, деревья);
- `physics.h` — коллизии игрока с вокселями, гравитация, полёт;
- `render.h` — GLSL-шейдеры, сборка и отрисовка меша мира, небо, UI;
- `input.h` — сенсорное управление (джойстик, кнопки, камера);
- `math_utils.h` — матричная математика.
